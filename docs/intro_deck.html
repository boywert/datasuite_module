DataSuite
SQL first, Python where it helps

One toolkit to pull data from DB2, Impala, files and SFTP, keep it on your machine, and work on it with the SQL you already know.

Audience: SQL users new to Python Presenter: Add: name Date: Add: date
Why

The work around the query takes longer than the query

Today

  • Open an SSH tunnel and configure a driver before the first SELECT.
  • Re-run a heavy query against production every time you change a filter.
  • Data from DB2, Impala and partner files can't be joined in one query.
  • Copy results into Excel and format them by hand every month.

With DataSuite

  • Tunnels, drivers and credentials are handled for you.
  • Pull a large result once, then query your local copy in seconds.
  • Join any sources together with plain SQL.
  • One line writes a formatted Excel report you can re-run next month.

Objectives

What we want to achieve

  • SQL stays your main language. Most of your work is SQL in notebook cells; Python is the glue.
  • Less load on production databases. Extract once into a local store, explore as often as you like.
  • One place for every source. DB2, Impala, BigQuery, CSV/Excel files and SFTP feeds end up as tables you can join.
  • Repeatable work. A notebook is a documented, re-runnable procedure, not a one-off.
  • Safe by default. Passwords live in environment variables or the vault, never in notebooks; saves never half-overwrite data.

First query

Query DB2 directly

from datasuite import DB2Connect

db2 = DB2Connect()
df = db2.query("""
    SELECT branch_id, COUNT(*) AS txns, SUM(amount) AS total
    FROM SALES.TRANSACTIONS
    WHERE txn_date >= '2026-01-01'
    GROUP BY branch_id
""")
df
  • Opens the tunnel, connects, fetches in batches, and closes everything again.
  • Same for Impala: ImpalaConnect().query("…").
  • Good for small and medium results. For large extracts, save instead (next slide).
  • If something is wrong you get a clear error message, not an empty result.

Core idea

Save once, query many times

from datasuite.parquet_store import DataStore
store = DataStore("datasets")    # a folder for your tables
store.enable_magic()
%%save sales_2026 --conn db2
SELECT *
FROM SALES.TRANSACTIONS
WHERE txn_date >= '2026-01-01'
%%query --var df_branch
SELECT branch_id, SUM(amount) AS total
FROM sales_2026
GROUP BY branch_id
ORDER BY total DESC
  • %%save streams the result to disk in chunks, so big extracts don't fill memory.
  • sales_2026 is now a table you can query, join and reuse after a restart.
  • --var df_branch keeps the result for the next step.
Combine sources

Join DB2 with Impala in one query

%%save branches --conn impala
SELECT branch_id, region, branch_type
FROM ref.branches
%%query --var df_region
SELECT b.region,
       COUNT(*)      AS txns,
       SUM(s.amount) AS total
FROM sales_2026 s
JOIN branches b USING (branch_id)
GROUP BY b.region
ORDER BY total DESC
  • Each source is saved as its own table.
  • The join runs locally, not on either server.
  • Works the same for BigQuery, files and SFTP data.
  • Named connections (other servers, vault credentials) are set up once in connections.yaml.

Putting it together

A monthly report, end to end

  1. Extract the month from DB2 with %%save sales_month --conn db2 --mode replace.
  2. Add reference data from Impala and the targets spreadsheet with %%save … --conn impala and %%save … --file.
  3. Summarise with %%query --var …: totals by region, variance against target.
  4. Deliver with export_excel(...).
  5. Next month: change the date in step 1 and run all cells.

Good habits

Tips and common mistakes

  • Large results: use %%save, not db2.query, so data streams to disk.
  • Table already exists? Saving again stops with an error on purpose. Add --mode replace or --mode append.
  • Name tables in snake_case (sales_2026). A name like my-data must be written "my-data" in SQL.
  • Read the last line of an error. It usually says exactly what is wrong (wrong password, missing table, bad name).
  • No passwords in notebooks. Use environment variables or the vault.
  • After enable_magic(), %save means DataSuite's save, not Jupyter's built-in one.
